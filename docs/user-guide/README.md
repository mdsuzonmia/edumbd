# Edum — User & Administrator Guide

This folder contains end-user and administrator documentation for **Edum**, a multi-tenant
School Management System (SaaS). The system is used by schools that subscribe to the platform,
and by the platform team that operates it.

## How to read these guides

If you are unsure where to begin, start with the file that matches your role in the table below.

| # | Guide | Read this if you are… |
|---|-------|----------------------|
| 00 | [Overview & Getting Around](00-overview.md) | Everyone — start here |
| 10 | [Signing Up & Onboarding](10-registration.md) | A school registering for the platform |
| 30 | [School Owner](30-school-owner.md) | Someone who owns/manages one or more schools |
| 60 | [Student](60-student.md) | A student using the portal |
| 80 | [Examinations & Results](80-examinations.md) | The owner-led exam, grading & reporting workflow |
| 90 | [Public Features & Utilities](90-public-and-extras.md) | QR verification, backups, SMS, certificates |

## Role quick-map

| Role | What they can do | Main guide |
|------|------------------|------------|
| **School Owner** | Run one/more schools; subscription & billing; academics, students, staff, teachers, examinations | [30](30-school-owner.md), [80](80-examinations.md) |

## Conventions used in these guides

- **Menu names** are shown in **bold**; screens/buttons are shown in `code`.
- "Trash / restore" refers to the soft-delete workflow used across the app: deleted items are
  moved to a trash collection and can be restored or permanently emptied.
- Paths like `/school-owner/students` are the URL routes in the application.
