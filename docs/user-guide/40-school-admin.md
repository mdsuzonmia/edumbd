# 40 — School Admin

This guide is for the **School Admin** — the person managing a school's day-to-day academic
operations. Routes are under `/admin` and require the `school-admin` role.

## Dashboard

**Dashboard** (`/admin/dashboard`) shows an overview and quick links for the school.

## Academics

Practical management of the school's academic structure.

- **Academic Years** — add/edit, set active year, trash/restore (`/admin/academics/years`).
- **Academic Classes** — define classes (`/admin/academics/classes`).
- **Academic Sections** — add sections under classes (`/admin/academics/sections`).
- **Academic Subjects** — add and manage subjects (`/admin/academics/subjects`).
- **Syllabus** — create syllabus topics per subject/class/term and edit/trash them.
- **Routines** — build class routines; edit and trash them.

Each academics screen supports: **Create**, **Edit**, **Trash/Delete**, **Restore** and
**Empty trash** (soft-delete workflow).

## Students

- **Students** (`/admin/students`) — list all students.
- **Add a student** — create a record (name, enrollment, guardian/address, documents).
- **Edit / Delete / Restore** — maintain records.
- **CSV upload** (`/admin/students/csv_upload`) — upload students from a CSV file in bulk
  (an alternative to the owner's JSON/CSV import).

## Results & reports

The exam results themselves are generated by the school owner via the examination module, but
the school admin can view and work with results inside the school area:

- **Results** (`/admin/academics/results`) — view results filtered by student, class, section,
  subject or exam.
- **Results by class** (`/admin/academics/results/class`) — see all students of a class with
  their results together.
  - **Print all results of a class** (`/results/class/print/{id}`).
  - **Tabulation sheet** for a class (`/results/class/tabulation/{id}`).
- **Result remarks** — the principal/head teacher can add remarks to results.
- **Student promotion** — promote students to the next class/year from the academics area.

## Custom fields

- **Custom Fields** (`/admin/custom-fields`) — manage the school's custom fields, **groups** and
  **options**, and save/read field **values** on records (AJAX).

## Common tasks (quick reference)

| I want to… | Go to |
|------------|-------|
| Set up this year's classes | `/admin/academics/classes` |
| Add a new subject | `/admin/academics/subjects` |
| Add a few students | `/admin/students` → Create |
| Upload many students | `/admin/students/csv_upload` |
| Print a class's report card | `/admin/academics/results/class` → Print |
| Add custom info to students | `/admin/custom-fields` |
